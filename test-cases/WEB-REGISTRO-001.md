# WEB-REGISTRO-001 – Validation for empty required fields

## Description
Verify validation messages when submitting empty registration form


## Module
User Registration


## Preconditions
User is on "Sign Up" page


## Steps

1. Navigate to "Sign Up"
2. Leave all fields empty
3. Click "Create"


## Expected Result
System should display validation messages for all required fields


## Actual Result
Validation is shown only for Email and Password fields


## Status
Failed


## Notes
Validation behavior is inconsistent across fields
